# Eleventy site revamp

- Posts and galleries are now generated from the posts/ directory.
- Use .md or .html files for posts.
- Place images for galleries in subfolders (e.g., posts/turbo/img/).
- Templates and config are in .eleventy/.
- To build: `npx @11ty/eleventy` from the project root.

Simple, static, Web 1.0 look and feel.
